# Playground

A blank Vite + React 19 + TypeScript sandbox with the React Compiler enabled.

```bash
npm run dev
```

Edit [`src/App.tsx`](src/App.tsx) freely. It's yours. Add files, try the lesson snippets, break things.

Want a test? Put a `*.test.tsx` file anywhere in `playground/` and run `npm test -- playground`. [`src/App.test.tsx`](src/App.test.tsx) is an example.
